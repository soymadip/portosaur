# @portosaur/app

The Portosaur Astro app — the integration, pages, layouts, components and assets for portfolio and docs sites.

## Structure

- **src/** — The Astro integration (`integration.ts`), pages, layouts, components, CSS and utilities.
- **assets/** — Default images and icons.
- **static/** — Static files copied into every site build.
- **tests/** — Unit tests.
