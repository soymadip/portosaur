# NOTICE

Portosaur's docs UI incorporates code derived from
[Starlight](https://github.com/withastro/starlight) (the documentation
theme for Astro), which is distributed under the MIT License.

Derived files live in `src/css/` (the CSS system, integrated into
Portosaur's own stylesheets — `variables.css`, `reset.css`,
`content.css`, and the other files in that directory) and in the
docs components and scripts adapted from Starlight's
(`src/components/`, `src/layouts/`, `src/scripts/`); each derived file
carries a header comment noting the derivation. Starlight identifiers
were renamed throughout the derived code: the `sl-` prefix became
`porto-`, `starlight` became `porto`/`portosaur`, and visible
Starlight branding was replaced with Portosaur's.
