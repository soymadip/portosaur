Portosaur exports custom UI components globally through `@portosaur/app`. You do not need to import them into your MDX files.

`<Btn>` and `<Dropdown>` are thin MDX wrappers around the app's shared `Button` and `Dropdown` components — the same Button renders the page actions and the dropdown triggers, and the same Dropdown renders the navbar menus and the theme select. Styling them in `custom_css` (`.porto-button`, `.porto-dropdown`) styles every button and menu on the site at once.

---

## `<Btn>`

The `<Btn>` component provides styled action buttons with built-in client-side routing and icons.

### Basic Usage

```jsx
<Btn>Default Button</Btn>
```

### Color Variants

Pick a variant with the `variant` prop, and add `outline` for the outlined form:

```jsx
<Btn variant="primary">Primary</Btn>
<Btn variant="secondary">Secondary</Btn>
<Btn variant="success">Success</Btn>
<Btn variant="info">Info</Btn>
<Btn variant="warning">Warning</Btn>
<Btn variant="danger">Danger</Btn>
<Btn variant="ghost">Ghost</Btn>
<Btn variant="primary" outline>Outlined</Btn>
```

<Btn variant="primary">Primary</Btn> <Btn variant="secondary">Secondary</Btn>
<Btn variant="success">Success</Btn> <Btn variant="info">Info</Btn>
<Btn variant="warning">Warning</Btn> <Btn variant="danger">Danger</Btn>
<Btn variant="ghost">Ghost</Btn>
<Btn variant="primary" outline>
  Outlined
</Btn>

### Sizes

```jsx
<Btn size="sm">Small</Btn>
<Btn size="lg">Large</Btn>
```

### Links & Navigation

Passing `to` renders a Next.js `<Link>`; passing `href` renders a plain anchor:

- **Internal Links** (`to`): navigate client-side, without a full page reload.
- **External Links** (`href`): automatically open securely in a new tab with `target="_blank"` and `rel="noopener noreferrer"`.
- **`sameTab`**: Forces external links to open within the existing tab.

```jsx
<Btn variant="primary" to="/docs/getting-started/installation">
  Install Now
</Btn>

<Btn variant="secondary" href="https://github.com/soymadip/portosaur">
  GitHub Repo
</Btn>
```

### Props Reference

| Prop        | Type                                                                                  | Default     | Description                                                                        |
| :---------- | :------------------------------------------------------------------------------------ | :---------- | :--------------------------------------------------------------------------------- |
| `variant`   | `"primary" \| "secondary" \| "success" \| "info" \| "warning" \| "danger" \| "ghost"` | `"primary"` | Sets the button's color.                                                           |
| `outline`   | `boolean`                                                                             | `false`     | Outlined form: a colored border with a transparent background that fills on hover. |
| `size`      | `"sm" \| "lg"`                                                                        | None        | Small or large size.                                                               |
| `to`        | `string`                                                                              | None        | Internal page path. Renders a Next.js `<Link>` with client-side navigation.        |
| `href`      | `string`                                                                              | None        | Link destination. External URLs open in a new tab unless `sameTab` is set.         |
| `sameTab`   | `boolean`                                                                             | `false`     | Keep an external `href` in the current tab.                                        |
| `icon`      | `string`                                                                              | None        | Icon identifier (for example `"lucide:download"`), rendered before the label.      |
| `className` | `string`                                                                              | `""`        | Additional class on the rendered element.                                          |
| `disabled`  | `boolean`                                                                             | `false`     | Disables button interaction and applies disabled styling.                          |
| `onClick`   | `function`                                                                            | None        | Click handler. Receives the click event.                                           |
| `title`     | `string`                                                                              | None        | Native title attribute on the rendered element.                                    |
| `ariaLabel` | `string`                                                                              | None        | Accessible label for the button.                                                   |

```jsx
<Btn icon="lucide:download" variant="primary">
  Download
</Btn>
```

<Btn icon="lucide:download" variant="primary">
  Download
</Btn>

## `<Dropdown>`

Renders an interactive dropdown menu for links or action items. A click opens the menu — there is no hover-open, so it works on touch too. Clicking an item, clicking elsewhere, or pressing Escape closes it. The menu centers under the trigger by default and shifts back inside the viewport when it would overflow.

```jsx
<Dropdown
  label="Jump to"
  items={[
    { label: "Getting Started", to: "/docs/getting-started" },
    { label: "CLI Reference", to: "/docs/cli-reference" },
    { label: "Markdown", to: "/docs/markdown" },
  ]}
/>
```

<Dropdown
  label="Jump to"
  items={[
    { label: "Getting Started", to: "/docs/getting-started" },
    { label: "CLI Reference", to: "/docs/cli-reference" },
    { label: "Markdown", to: "/docs/markdown" },
  ]}
/>

### Props Reference

| Prop               | Type                            | Default    | Description                                                                        |
| :----------------- | :------------------------------ | :--------- | :--------------------------------------------------------------------------------- |
| `label`            | `string`                        | `"Menu"`   | Text for the default trigger.                                                      |
| `trigger`          | `ReactNode \| string`           | None       | Custom trigger content. If omitted, `label` is used.                               |
| `items`            | `DropdownItem[]`                | None       | Menu entries described below.                                                      |
| `children`         | `ReactNode`                     | None       | Menu content when no `items` are given.                                            |
| `align`            | `"left" \| "center" \| "right"` | `"center"` | Menu alignment relative to the trigger. The edge clamp applies to every alignment. |
| `noArrow`          | `boolean`                       | `false`    | Hide the trigger chevron.                                                          |
| `className`        | `string`                        | `""`       | Additional class on the dropdown wrapper.                                          |
| `menuClassName`    | `string`                        | `""`       | Additional class on the menu.                                                      |
| `triggerClassName` | `string`                        | `""`       | Additional class on the trigger.                                                   |
| `ariaLabel`        | `string`                        | None       | Accessible label for the trigger.                                                  |

Regular items support `label`, `to`, `href`, `icon`, `active`, `onClick`, `sameTab`, `desc`, and `prefetch` (`false` skips Next.js prefetch for that link). `to` is an internal page path (client-side navigation); `href` is a full URL or absolute path, and external links open in a new tab unless `sameTab` is true. Use `{ type: "separator" }` for a divider. An item can instead provide `render: ({ close }) => ReactNode` for custom content and to close the menu programmatically.

## `<Icon>` & `<DynamicIcon>`

Display bundled vector icons by passing the identifier through the required `id` prop:

```jsx
<Icon id="si:github" />
<Icon id="md:settings" />
<Icon id="lucide:rocket" />
```

`Icon` also accepts `size`, `color`, `className`, `style`, and `addSpace` (append a space after the icon).

`<DynamicIcon>` resolves a frontmatter-style icon value, a slug, or a fallback icon:

```jsx
<DynamicIcon iconStr="🚀" />
<DynamicIcon slug="react" fallbackIcon="md:code" />
```

`iconStr` accepts an icon identifier, emoji, image path/URL, inline SVG string, or `{ src, fallback }` object. Without `iconStr`, `slug` is checked against Portosaur's technology map and bundled devicons before `fallbackIcon` is used. It also accepts `className` and `style`.

## `<IconSearch>`

An interactive icon explorer widget that allows users to search, filter, and copy icon identifiers directly within your documentation pages:

```jsx
<IconSearch />
```

Use `dropUp` to position the filter menu and results above the search field when space below is limited:

```jsx
<IconSearch dropUp />
```
