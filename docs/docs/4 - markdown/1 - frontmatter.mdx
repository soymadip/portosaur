Frontmatter is the YAML block at the very top of your Markdown (`.md` or `.mdx`) files between triple-dashed lines `---`.

It lets you configure document metadata and behavior. Portosaur adds note-specific options on top of the standard fields used by docs and blog posts.

```yaml
---
title: JavaScript Tips
slug: custom-url-path
desc: Advanced tricks and tips for JS.
icon: 🚀
color: "#F7DF1E"
sidebar_label: JS Tips
pagination_label: JavaScript
hide_table_of_contents: false
topic_list:
  enable: true
  class: "my-custom-grid-row"
---
```

## Frontmatter Reference

These options apply to documents in the configured notes/docs directory; see the blog reference below for common blog fields.

| Field                        | Type        | Default                                | Description                                                                                                                                                                                                                      |
| :--------------------------- | :---------- | :------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`title`**                  | `str`       | 1st heading or filename                | Document title.                                                                                                                                                                                                                  |
| **`desc`**                   | `str`       | 1st para when available                | Summary used for page metadata and note cards.                                                                                                                                                                                   |
| **`slug`**                   | `str`       | Generated from the file path           | Overrides the URL path.<br/>- Portosaur removes numeric ordering prefixes from generated paths.<br/>- A leading `/` makes the slug relative to the configured docs/notes route, otherwise it is relative to the containing path. |
| **`icon`**                   | `str`       | `null`                                 | Emoji or icon identifier shown in note and topic cards.                                                                                                                                                                          |
| **`color`**                  | `str`       | Theme/default card color               | CSS color for the page's note-card accent & sidebar/topic-card icon.                                                                                                                                                             |
| **`sidebar_label`**          | `str`       | `title`                                | Custom label shown in the sidebar.                                                                                                                                                                                               |
| **`sidebar_collapsed`**      | `bool`      | Global `sidebar_collapsed`             | Start this page with the sidebar closed (`false` forces it open, overriding the global `theme.navigation.sidebar_collapsed`).                                                                                                    |
| **`pagination_label`**       | `str`       | `title`                                | Label used for previous/next document navigation. Coming soon — not used yet.                                                                                                                                                    |
| **`hide_table_of_contents`** | `bool`      | `false`                                | Hides the desktop and mobile table of contents for this document. Coming soon — not used yet.                                                                                                                                    |
| **`hide_title`**             | `bool`      | `false`                                | Hides the page title above the content.                                                                                                                                                                                          |
| **`math`**                   | `bool`      | `false`                                | Loads the math stylesheet for this page. Math in content is usually detected automatically — set this when a page needs it anyway.                                                                                                |
| **`draft`**                  | `bool`      | `false`                                | Draft notes are omitted from Portosaur note-card lists in production. This does not by itself prevent direct access to the document.                                                                                             |
| **`unlisted`**               | `bool`      | `false`                                | Omits the note from Portosaur note-card lists in all environments. It does not by itself prevent direct access to the document. Coming soon — not used yet.                                                                        |
| **`image`**                  | `str`       | `null`                                 | Image path or URL used for page/social metadata. Coming soon — not used yet.                                                                                                                                                     |
| **`topic_list`**             | `bool/obj`  | Global setting on category index pages | Shows or hides the child-topic card list.<br/> See the options [below](#topic_list-options).                                                                                                                                     |
| **`source`**                 | `str/str[]` | `null`                                 | URL or list of URLs for the preview button in the action bar above the table of contents. Coming soon — not used yet.                                                                                                            |

### `topic_list` Options

- Set `topic_list` to `false` to disable the list, or `true` to enable it on the page.
- Use an object to configure the list:

| Option       | Type      | Default                                                 | Description                                          |
| :----------- | :-------- | :------------------------------------------------------ | :--------------------------------------------------- |
| **`enable`** | `boolean` | Automatic on category index pages when globally enabled | Enables or disables the list on this page.           |
| **`class`**  | `string`  | None                                                    | Additional CSS class name(s) on the topic-card grid. Coming soon — not used yet. |

<br />

:::info
By default, topic lists are automatically added to category landing pages such as `README.mdx` and `index.mdx`.

- Configure `site.notes.topic_list: false` in `config.yml` to disable this default globally.
- An explicit `topic_list: true` or `topic_list.enable: true` can enable a list on an individual page then.

:::

## Blog Frontmatter

Blog posts use Portosaur's blog pages. Common fields include:

```yaml
---
title: My First Post
desc: Notes from the first release.
date: 2026-11-12T10:00
authors: [you]
tags: [release, notes]
draft: false
image: /img/blog-cover.jpg
slug: first-release
---
```

| Field         | Type                 | Default                                    | Description                                                                            |
| :------------ | :------------------- | :----------------------------------------- | :------------------------------------------------------------------------------------- |
| **`title`**   | `string`             | Filename                                   | Post title.                                                                            |
| **`desc`**    | `string`             | None                                       | Short post summary used in metadata and previews.                                      |
| **`slug`**    | `string`             | Generated from the file path/date          | Overrides the post URL.                                                                |
| **`date`**    | `date`               | Date in filename or file modification time | Publication date.                                                                      |
| **`authors`** | `string \| string[]` | None                                       | Author key or keys defined in the blog's authors configuration.                        |
| **`tags`**    | `string[]`           | None                                       | Tags used to categorize the post.                                                      |
| **`draft`**   | `boolean`            | `false`                                    | Draft filtering for blog posts is coming soon — today `draft` only hides notes from note-card lists. |
| **`image`**   | `string`             | None                                       | Cover image path or URL used for social sharing and previews. Coming soon — not used yet.          |

Other frontmatter keys are ignored. For Portosaur's `{vars.*}` variables in Markdown and MDX, see [Dynamic Variables](/docs/config/dynamic-variables/).
