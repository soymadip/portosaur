{vars.project.title} is built on top of Fumadocs and [MDX]({vars.tools.mdx}), giving you the simplicity of the markdown and expressiveness of React snippets.

Tables carry a copy button in the top-right corner. It copies the whole table as Markdown, with the header alignment kept, so it pastes straight back into another page.

Images open bigger when clicked, in a viewer that fills the screen on a phone. Inside the viewer, pinch or Ctrl+scroll to zoom in further and drag to move around, or use the zoom buttons at the bottom right. Images inside a link keep their link instead.
