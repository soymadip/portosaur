---
title: "IconSearch"
desc: "Search, filter, and copy icon identifiers in-page."
icon: "lu:search"
---

An interactive icon explorer widget that allows users to search, filter, and copy icon identifiers directly within your documentation pages:

```jsx
<IconSearch />
```

Try it live:

<IconSearch />

Press Escape to close the results list. It opens again when you keep typing or click back into the search field.

Use `dropUp` to position the filter menu and results above the search field when space below is limited:

```jsx
<IconSearch dropUp />
```

<IconSearch dropUp />
