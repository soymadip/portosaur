{vars.project.title} supports two types of sites:

### 1. Portfolio Site

- **Built for individuals.**
- Includes a customized hero section, about bio, interactive project showcase, career timeline, blog, digital notebook, and public task tracker.

### 2. Documentation Site

- **Built for projects, libraries, and tools.**
- Includes a docs homepage with features cards, call-to-actions, nested docs categories, search, and integrated blog.
