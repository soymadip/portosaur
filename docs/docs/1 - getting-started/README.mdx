Here you will find guides on installing Portosaur, setting up your environment, and understanding the generated project architecture.

## Quick Overview

Portosaur supports two types of sites:

1. **Portfolio Site**: Built for individuals. Includes a customized hero section, about bio, interactive project showcase, career timeline, blog, digital notebook, and public task tracker.

2. **Documentation Site**: Built for projects, libraries, and tools. Includes a docs homepage with features and call-to-actions, nested documentation categories, search, and integrated blog.
