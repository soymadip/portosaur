Every Portosaur site comes with search built in — no setup, no server. The search index is built with your site, and searching runs entirely in the visitor's browser.

## Opening search

- Press <kbd>Cmd</kbd>/<kbd>Ctrl</kbd> + <kbd>K</kbd> anywhere on the site.
- Or tap the search button in the top bar.

## Results

Results are a plain list, like Fumadocs': each matching page shows its path above its title, then its matching headings (marked with a `#`) and text underneath. Matching words are bold, in the accent color, and underlined. Matches inside tables show as table rows, so you can see the row your words came from. Clicking a result flashes what you clicked briefly on the page you land on, so you can see where your words came from: the heading for a heading result, the line itself for a text or table result, and the page title for a page result.

The search bar is Fumadocs' bar: a magnifier, a borderless input, and an ESC button that closes it. The dialog opens above the middle of the screen with a taller bar, then slides up and shrinks the bar to its normal height once results appear, so the list has room to grow downward. It fades and scales in, and shrinks away when it closes. While it is open, the page behind stays visible through a light blur. When results come from more than one section, the ESC button swaps for a filter dropdown that narrows them to a single section, so the dialog never changes size.

## Keyboard

- <kbd>↑</kbd> / <kbd>↓</kbd> move through results.
- <kbd>Enter</kbd> opens the selected result.
- <kbd>Esc</kbd> closes search.

## The search page

`/search` is a full-page version of the same search, with the same grouped results and section filter, plus a count of how many results matched.

## What search covers

Search covers your docs pages — or your notes, on a portfolio site. Blog posts aren't in the index yet.
